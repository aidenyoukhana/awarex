# Awarex

A real-time safety and incident awareness app for iOS.

## Overview

Awarex keeps you informed about emergencies, incidents, and safety alerts happening in your area. Stay aware, stay safe.

## Features

- 📍 Real-time local incident alerts
- 🚨 Emergency notifications
- 🗺️ Interactive incident map
- 🔔 Customizable alert preferences

## Requirements

- iOS 17.0+
- Xcode 15.0+
- Swift 5.9+

## Getting Started

1. Clone the repository
2. Open `Awarex.xcodeproj` in Xcode
3. Build and run on your device or simulator
